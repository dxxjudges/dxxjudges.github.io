Shared Core

共享的评测内核

两个项目的判题语义保持一致：同一份题面与测试数据，可以在两套系统上得到相同的评测结果。

统一的评测语义

  • 严格 / 宽松 / 浮点容差 / Special Judge
  • 子任务计分：分组、依赖、聚合策略
  • 交互式评测：interactor 与 grader
  • 逐测试点计时与峰值内存统计

可扩展的语言体系

  • 内置 C / C++ / Python / Java / JavaScript
  • CliJudge：custom_languages 注册任意扩展名
  • NoldOJ：管理面板动态添加与禁用语言
  • 显示语言包 .cjl，可联网切换

题库互通

  • LemonLime CDF 导入导出
  • CliJudge：zip 打包导入导出题目
  • NoldOJ：题目 / 测试点在线批量上传
  • Markdown + KaTeX 题面，样例一键复制

比赛与题单

  • 创建比赛、绑定题目、实时排行榜
  • 封榜 / 解冻、HTML 比赛报告导出
  • NoldOJ：邀请制参赛、虚拟比赛
  • NoldOJ：题单训练计划与数据看板

无数据库负担

  • NoldOJ：内置 node:sqlite，WAL 模式
  • CliJudge：纯 JSON 文本，便于备份与版本控制
  • 数据目录自定义，CliJudge 支持环境变量覆盖
  • 旧版数据结构启动时自动迁移

安全治理

  • 不可信代码一律在完整沙箱内执行
  • SPJ / 生成器 / grader 以可信模式运行并保留时限
  • 导入携带此类代码的题目包时显式告警
  • NoldOJ：JWT 双令牌、限流、SQL 注入防护
Security

纵深防御的安全沙箱

两个项目共享同一套沙箱设计思路：基于操作系统原生的进程隔离能力，把不可信代码关进受控环境。

01

进程树隔离

CREATE_SUSPENDED + Job Object 绑定，杜绝竞态逃逸。

02

强制回收

KILL_ON_JOB_CLOSE，主进程结束则整棵进程树被系统强制秒杀。

03

禁止脱离

禁用 BREAKAWAY，子进程无法脱离沙箱。

04

权限降级

受限令牌剥离 SeDebug / SeImpersonate 等高危特权，Low IL 运行。

05

跨平台隔离

Linux 侧 namespaces + seccomp + 只读挂载 + RLIMIT，能力与 Windows 侧对齐。

06

自动降级

评测前能力预检，加固环境（限制 user namespace）自动降级，不中断评测。

07

资源限制

内存上限、CPU 时间限制、进程数限制多重保障。

08

数据隔离

每次判题独立临时目录，结束后暴力删除。

09

失败即拒绝

NoldOJ 未编译沙箱运行器时默认 fail-closed 拒绝判题，不静默裸跑。

⚠️ Windows 桌面系统并非为绝对隔离设计，请勿在存有核心机密的个人主力机上以公网暴露形式运行，建议部署在虚拟机或专用测试机中。

Quick Start

快速开始

两条命令，各拉起一套评测环境。

# NoldOJ：克隆并启动（需 Node.js 24+）
git clone https://github.com/dxxjudges/NoldOJ.git
cd NoldOJ
cd backend && npm install && cd ..
start.bat

# 浏览器打开 http://localhost:3000
  1. NoldOJ：安装 Node.js 24+ 与 MinGW-w64，或直接下载一键安装包
  2. 管理员账号 admin，初始密码随机生成，首次启动日志中显示一次，登录后请立即修改
  3. 未编译 sandbox_runner.exe 时系统默认拒绝判题，可用 MinGW 执行 backend\sandbox\build.bat 编译
# CliJudge：一行安装（需 Node.js ≥ 14）
npm install -g clijudge

# 或从源码构建
git clone https://github.com/dxxjudges/clijudge.git
cd clijudge
mkdir build && cd build
cmake .. && cmake --build .

# 上手
clijudge problem create "A + B Problem"
  1. CliJudge：npm 会自动按平台与架构挑选预编译二进制
  2. 也可从 Releases 直接下载 clijudge.exe / clijudge-linux.bin
  3. 数据默认存放在可执行文件同级的 data/，可用 CLIJUDGE_DATA_DIR 覆盖

FAQ

常见问题

我该选 NoldOJ 还是 CliJudge？

需要给学校、团队或公开站点提供完整的做题 / 比赛 / 排行体验，选 NoldOJ；只需要在本地或服务器上批量评测题库、跑脚本化流水线，选 CliJudge。两者题面与评测语义互通，数据可通过 LemonLime CDF 迁移。

两个项目会同时维护吗？

会。NoldOJ 与 CliJudge 是同一组织下的两个独立仓库，各自有独立的版本节奏、Wiki 与发布页。

可以商用或二次开发吗？

可以。两个项目均采用 MIT License，允许商业使用、修改与再分发，保留版权声明即可。

沙箱是否绝对安全？

不是。沙箱基于操作系统原生隔离能力构建，能有效阻断常见的越权与逃逸路径，但操作系统桌面环境并非为绝对隔离设计。涉及不可信公网流量时，请部署在虚拟机或专用测试机中。
